# دليل إعداد وتشغيل السحابة (Supabase) لتطبيق Engine Rowing

أهلاً بك يا كوتش. هذا الدليل مكتوب بخطوات بسيطة ومرقمة وبدون أي مصطلحات برمجية معقدة لربط التطبيق بالسحابة لأول مرة.

---

### الخطوة 1: إنشاء مشروع مجاني على Supabase
1. ادخل على الموقع: [https://supabase.com](https://supabase.com) واضغط على **Start your project** وسجل دخول بحساب Google أو GitHub.
2. اضغط على **New project** (مشروع جديد).
3. اكتب اسم المشروع: مثلاً `engine-rowing`.
4. اكتب كلمة سر قوية لقاعدة البيانات (واحتفظ بها في مكان آمن).
5. في خانة **Region** (المنطقة الجغرافية)، اختر الأقرب لمصر والشرق الأوسط: **Frankfurt (eu-central-1)**.
6. اضغط على **Create new project** وانتظر دقيقة أو دقيقتين حتى يكتمل تجهيز المشروع.

---

### الخطوة 2: نسخ مفاتيح الربط من لوحة التحكم
1. من القائمة الجانبية اليسرى للمشروع، اضغط على أيقونة الترس ⚙️ **Project Settings**.
2. اختر من القائمة الفرعية **API**.
3. ستجد قسمين مهمين:
   - **Project URL**: اضغط على زر Copy لنسخ الرابط (يبدأ بـ `https://...`).
   - **Project API keys**: انسخ المفتاح المسمى **`anon` `public`** (ممنوع نهائياً نسخ أو استخدام مفتاح `service_role`).

---

### الخطوة 3: لصق المفاتيح داخل ملف الإعدادات
افتح الملف التالي في المشروع:
```text
lib/cloud_config.local.dart
```
*(هذا الملف محفوظ ومستثنى تلقائياً من الـ Git لحماية بياناتك ومفاتيحك)*

ضع الرابط والمفتاح بين علامتي التنصيص هكذا:
```dart
const String localSupabaseUrl = 'الصق_هنا_رابط_المشروع';
const String localSupabaseAnonKey = 'الصق_هنا_مفتاح_anon_public';
```
ثم احفظ الملف (`Ctrl + S`).

---

### الخطوة 4: تشغيل ملف الجداول والصلاحيات (SQL Migration)
1. من القائمة الجانبية في موقع Supabase، اضغط على أيقونة **SQL Editor**.
2. اضغط على **New query** (استعلام جديد).
3. افتح الملف المجهز لك في المشروع:
```text
supabase/migrations/0001_init.sql
```
4. انسخ كل ما بداخل الملف بالكامل، والصقه في شاشة الـ SQL Editor.
5. اضغط على زر **Run** الأخضر أسفل اليمين.
6. ستظهر لك رسالة خضراء: `Success. No rows returned`، وهذا يعني أن جميع الجداول (اللاعبين، الحصص، التمارين، الاشتراكات، وقواعد الأمان RLS) تم إنشاؤها بنجاح وبأمان تام.

---

### الخطوة 5: إنشاء حساب الأدمن وترقيته
1. افتح تطبيق Engine Rowing.
2. اذهب إلى شاشة **إنشاء حساب جديد** (Sign Up).
3. سجّل حساباً جديداً بالبريد الإلكتروني المعتمد للأدمن:
```text
admin.mabdelhalimdawod@engine.rowing
```
4. بعد التسجيل مباشرة، سيظهر لك تنبيه بأن الحساب في انتظار التفعيل (لأن النظام يمنع أي شخص من التسجيل كأدمن من داخل التطبيق لحمايته).
5. ادخل مرة ثانية على **SQL Editor** في Supabase، والصق السطرين التاليين واضغط **Run**:
```sql
-- ترقية حساب الأدمن وتفعيل اشتراكه بصلاحية كاملة
UPDATE public.profiles 
SET role = 'admin' 
WHERE LOWER(email) = 'admin.mabdelhalimdawod@engine.rowing';

UPDATE public.subscriptions 
SET active = true, note = 'حساب الأدمن الرئيسي مفعّل'
WHERE user_id = (SELECT id FROM public.profiles WHERE LOWER(email) = 'admin.mabdelhalimdawod@engine.rowing');
```
الآن أصبح الحساب أدمن ومفعّلاً رسمياً!

---

### الخطوة 6: الاختبار اليدوي السريع (4 خطوات للتأكد)
1. **تسجيل حساب لاعب جديد:**
   - افتح التطبيق وسجّل حساب لاعب جديد بأي إيميل تجريبي (مثلاً `player1@test.com`).
2. **الرسالة المحايدة:**
   - حاول تسجيل الدخول بالحساب الجديد فوراً.
   - النتيجة المتوقعة: يرفض الدخول ويعرض الرسالة المحايدة المعتمدة:  
     *«حسابك غير مفعّل حاليًا، تواصل مع الإدارة»*
3. **تفعيل الحساب من السحابة:**
   - في Supabase في جدول `subscriptions`، غيّر قيمة `active` الخاصة بهذا اللاعب إلى `true` (أو شغل استعلام التفعيل).
4. **الدخول والعمل أوفلاين:**
   - سجّل دخول بالحساب بعد تفعيله ← سيفتح التطبيق فوراً ويحفظ الجلسة محلياً، ويمكنك فتحه لاحقاً بدون اتصال بالإنترنت (في الجيم أو المياه).
