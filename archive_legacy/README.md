# Archive Legacy

This directory contains legacy and superseded source files from early iterations of the Engine Rowing project.

## Contents
1. **Root Legacy Files:**
   - `app_strings.dart`
   - `dashboard_tab.dart`
   - `db.dart`
   - `heart_rate_zones.dart`
   - `main.dart`
   - `player_entry_page.dart`
   - `player_profile.dart`
   - `power_calculations.dart`
   - `settings_tab.dart`
   - `workouts_tab.dart`

2. **Superseded `lib/` Files:**
   - `admin_placeholder.dart` (superseded by `lib/admin_page.dart`)
   - `player_entry_page.dart` (superseded by `lib/athlete_day_entry_page.dart`)
   - `settings_tab.dart` (superseded by in-app drawer settings dialogs)

## Notice
Active development and runtime production code reside exclusively in `lib/`. These files are preserved for forensic historical reference and are excluded from static analysis.
